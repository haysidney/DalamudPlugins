# HaySidney's Dalamud Plugin Repository

A custom plugin repository for [Dalamud](https://dalamud.dev/) (FFXIV).

## Adding it

1. In game, `/xlsettings` -> **Experimental** -> **Custom Plugin Repositories**
2. Paste this URL and press the **+**, then **Save**:

```
https://raw.githubusercontent.com/haysidney/DalamudPlugins/main/repo.json
```

3. The plugins below appear in `/xlplugins`.

## Plugins

| Plugin | What it does | Source |
|---|---|---|
| **Twenty One** | Run a blackjack table in an FFXIV venue - chat narration, card rolls, per-player banks, and gil reconciliation. | [haysidney/twenty-one](https://github.com/haysidney/twenty-one) |

Each plugin's code, releases and documentation live in its own repository; this
one only carries the manifest Dalamud reads.
